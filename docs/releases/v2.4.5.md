# SnapActions v2.4.5 — Open highlighted links without a prefix

Highlighting `youtube.com` now shows **Open URL**. Click the arrow icon to open it in your default browser; SnapActions adds `https://` automatically.

- Recognize complete bare domains, including subdomains, paths, ports, query strings and fragments.
- Build the correct destination even when a link contains another URL in its path or query string. Preserve explicit HTTP, HTTPS and FTP schemes.
- Preserve email, IP address and JWT detection, and reject malformed bare domains or selections containing extra prose.

## Validation

The link fix passed 622 .NET tests, 12 browser tests, compiled WPF checks and three native-host subprocess cases. A live Windows 10 test reproduced the missing action, then verified that highlighting `youtube.com` in Notepad showed **Open URL** and opened YouTube in Brave after the update. Saved settings, including the eight-action inline limit, were preserved.

The release includes `release-validation.json` for the committed package, hosted Windows CI and installed executable identity, and `live-validation.json` for the recorded desktop checks. These receipts identify the builds and scenarios actually tested.

## Upgrade

Exit SnapActions and replace the complete application folder contents with the new ZIP. Keep the executable and accompanying files together. Existing saved preferences are retained. The browser companion is unchanged; register it again only if the executable moved.
